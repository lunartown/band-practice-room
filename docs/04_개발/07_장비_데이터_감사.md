# 장비 데이터 감사

## 2026-08-30 전국 카탈로그 확장 점검

### 원칙

장비 근거는 다음 순서로 신뢰한다.

1. 스튜디오 공식 사이트·공식 SNS
2. 스튜디오 운영자가 관리하는 네이버 예약 상품 본문
3. 네이버 플레이스
4. 스페이스클라우드 등 예약 플랫폼
5. 밴드룸 등 제3자 카탈로그

밴드룸 공개 카탈로그는 조사 대상을 찾고 교차 확인하는 용도로만 사용한다. 밴드룸의
장비 문자열만으로 운영 데이터에 장비를 추가하거나 기존 장비를 삭제하지 않는다.

### 점검 범위와 결과

- 운영 기준 활성 스튜디오 233곳, 활성 룸 473개를 점검했다.
- 기존 `room_equipment`는 1,242건이며 장비가 하나 이상 연결된 룸은 192개였다.
- 기존 장비 근거 1,254건은 모두 2026-07-22 관찰분이었다.
- 기존 근거 URL 142개 중 139개가 HTTP 200으로 열렸다.
- 전국 카탈로그 확장으로 추가된 스튜디오는 105곳이다.
- 이 가운데 장비가 비어 있고 네이버 예약 상품에 연결된 146개 룸의 현재 상품 본문을
  전부 다시 조회했다.

네이버 예약 본문 분류 결과는 다음과 같다.

| 분류 | 룸 수 | 처리 |
| --- | ---: | --- |
| 모델 또는 구체 장비 목록 확인 | 63 | 장비 반영 |
| 장비 관련 문장은 있으나 구체 목록 없음 | 42 | 추정 반영하지 않음 |
| 장비 언급 없음 | 41 | 반영하지 않음 |

구체 목록 63개 룸에는 장비 연결 420건과 같은 수의 근거를 추가한다. 반영 후 예상치는
`room_equipment` 1,662건, 장비가 연결된 룸 255개다.

- `006_20260830_verified_naver_equipment.sql`: 6개 룸, 58개 장비. 명확한 모델은
  `equipment_models`에 연결하고 불명확한 표기는 원문 모델로 보존한다.
- `008_20260830_new_studio_naver_equipment.sql`: 57개 룸, 362개 장비. 룸별 장비 종류,
  수량, 원문 모델 표기를 보존하며 불명확한 표기는 `MEDIUM` 신뢰도로 둔다.
- `007_20260830_refresh_confirmed_equipment_evidence.sql`: 현재 네이버 상품 본문에서
  원문 또는 파싱명이 다시 확인된 기존 근거 260건의 `observed_at`을 갱신한다.

세 SQL을 운영 DB에서 하나의 트랜잭션으로 실행해 420개 신규 근거, 260개 갱신 근거,
총 1,662개 룸 장비가 만들어지는 것을 확인한 뒤 롤백했다.

### 보류한 항목

현재 네이버 본문에서 기존 근거 문자열을 찾지 못한 항목은 38개 스튜디오 655건이다.
네이버 페이지가 설명을 요약하거나 장비 표기를 다른 필드로 옮긴 경우도 있으므로,
이 결과만으로 장비가 철거됐다고 판단하지 않는다. 공식 사이트·공식 SNS와 대조하기
전에는 삭제하지 않는다.

응답이 비정상인 기존 근거 URL은 다음과 같다.

- `https://mple.kr/`: 접속 오류. 엠플사운드 5개 룸 28건에 연결되어 있다.
- `https://www.spacecloud.kr/space/59441`: HTTP 404. 리엠뮤직 잠실 5건에 연결되어 있다.
- `local://studio-catalog.json`: 외부 URL이 아닌 내부 카탈로그 근거 4건이다.

### 재점검 방법

다음 명령은 DB를 수정하지 않고 장비가 비어 있는 네이버 예약 룸의 현재 상품 설명을
수집한다. 출력 파일은 커밋하지 않는 `_local/` 아래에 둔다.

```bash
cd src/scraper
set -a
source "$(git rev-parse --git-common-dir)/render-db.env"
set +a
DATABASE_URL="$DATABASE_URL_PROD" npm run audit:equipment -- \
  --since-ref '1acb71d^' \
  --output ../../_local/equipment-audit.json
```

감사 스크립트는 `candidate`, `generic-only`, `no-signal`, `fetch-error`로만 분류한다.
`candidate` 결과도 운영 데이터에 넣기 전에 룸 이름과 원문 장비 목록을 사람이 확인해야
한다.

## 2026-08-30 추가 설명 재점검

네이버 예약 상품은 기본 설명 외에 `extraDescJson` 추가 설명에 장비표를 둘 수 있다.
기존 감사기는 기본 설명만 읽어 비커즈뮤직·언더그라운드·올사운드 등 29개 룸의
구체 장비표를 놓치고 있었다.

- 감사기의 네이버 상품 조회에 추가 설명 수집을 포함했다.
- 추가 설명에서 구체 장비표가 확인된 29개 룸에 장비·근거 198건을 추가한다.
- 현재 기본 설명에서 종류·수량이 명확한 21개 룸에 일반 장비·근거 89건을 추가한다.
- 모델이 없는 장비는 임의 모델을 만들지 않고 원문 표기와 `MEDIUM` 신뢰도를 보존한다.
- 두 SQL을 운영 DB에서 한 트랜잭션으로 실행해 50개 룸 287건이 추가되는 것을 확인한
  뒤 롤백했다.

이 배치까지 적용하면 `room_equipment`는 1,949건, 장비가 연결된 룸은 305개가 된다.
전국 카탈로그 확장분 중 아직 장비가 확인되지 않은 룸은 33개다.
